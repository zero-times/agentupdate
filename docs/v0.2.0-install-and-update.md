# AgentUpdate v0.2.0：安装、升级与应用内自更新

本轮优先支持本机 Codex CLI、Claude Code CLI、Deepseek Harness，以及 Codex / Claude 桌面应用。Gemini CLI 和 ChatGPT 应用保留在相同目录中。支持范围为固定工具目录；未知 Agent 尚需新增官方渠道适配器。

## CLI

- Codex CLI：官方 npm、标准 Homebrew Cask，检测实际版本、一键选取渠道版本、旧安装与配置备份、更新后核验和回滚。
- Claude Code CLI：官方 npm、用户原生安装、标准 Homebrew Cask。新 npm 分发中的平台原生二进制额外以 Claude 官方 manifest SHA256 核验；不执行 npm 生命周期脚本。
- Deepseek Harness：识别 `dsh` / `@deepseek-ai/dsh`；支持当前用户所有的标准 npm 安装，包括本机 `/opt/homebrew/lib/node_modules` 实例。官方 latest 当前为 `0.2.0-rc.2`，必须勾选允许预发行渠道；不会将 RC 显示成稳定版。
- Gemini CLI：官方 npm，保持指定版本与最新稳定版本更新及回滚。
- 缺失 CLI 安装到 `~/.local/bin` 和 `~/.local/lib/node_modules`。需要已有 Node.js 22.12+；不会修改 shell 启动配置，终端 PATH 应包含 `~/.local/bin`。
- 首次安装有单独的持久记录，可恢复为未安装；保留使用后生成的配置。如果安装内容后来改变，会拒绝删除以免移除其他版本。
- 更新现有实例始终保留安装来源。Homebrew latest 可以落后于厂商原生渠道，界面显示该实例对应渠道的版本；不会擅自混用或迁移来源。

Deepseek 备份范围为全局 `cordis.patch.yml`、`.credentials.yaml`，及每个 profile 的 `cordis.patch.yml`、`cordis.yml`、`package.json`、`pnpm-lock.yaml`、`pnpm-workspace.yaml`、`.credentials.yaml`。不跟随 profile `node_modules` 指向安装树的投影；完整 npm 安装与依赖另行备份。升级后如配置变化，回滚前保存变化副本。CLI 验证执行隔离的 `--version` 与 `--help`，不启动模型会话。

## Codex / Claude / ChatGPT 应用

1. 检测本机 bundle 身份、版本和架构，并查询公开稳定渠道。
2. 点击一键安装或下载并升级：后台下载、SHA256 核验、解包、bundle 版本/身份/架构及厂商签名验证，备份旧应用与受管配置。
3. 确认目标目录后发布新应用，核验完整文件树。失败时保留恢复记录和旧应用；安装记录可恢复旧应用或原始未安装状态。

已有实例必须位于 `/Applications` 或用户的 `~/Applications`，且当前用户具有写入权限。多个实例、改名开发构建、目录链接或运行中的目标应用会被明确拒绝，退出目标应用后即可重试。安装不会关闭用户正在使用的 Codex / Claude。本机的 `ChatGPT.app` 使用集成 Codex 身份，按产品名与可执行文件区分，避免误判为独立 Codex。

应用恢复保留当前配置；安装过程不会启动目标工具、修改登录信息或 Keychain。旧 bundle、受管配置备份、安装记录保存在 `~/Library/Application Support/AgentUpdate/app-installs`；请私下保管其中配置。Claude 滚动更新若领先于公开 SHA256 目录，会提示校验待发布，保留官方手动入口。

## AgentUpdate 应用内更新

参考 scriptser 指定会话的流程实现：GitHub Releases 检查 → 下载及 SHA256 校验 → bundle 身份/版本/架构/签名验证 → 保存旧应用 → 关闭确认面板并退出 → 独立后台 helper 等待旧进程退出、替换应用并重启。

- 安装按钮在下载和重启期间不可重复触发；后台进程保留独立会话和持久失败记录。
- 正常退出若停滞，退出 watchdog 完成进程结束；helper 有等待上限，超时不替换应用。
- API 网络失败或限流时，通过同仓库 `/releases/latest` 的跳转确认稳定 tag，并从该 tag 下读取 `SHA256SUMS` / `SHA256SUMS.txt`。拒绝重复条目、越界名称、非十六进制或非 64 位 SHA256、过大清单。
- 无可信 SHA256 时保留手动下载入口，自动安装不会降低校验要求。
- 当前运行应用须为标准 Applications 中的 AgentUpdate；开发构建不能自覆盖。自更新后的旧应用恢复也由后台 helper 完成。
- 后台安装已成功但 Launch Services 重启失败会记录 `installed_not_restarted`，可手动打开应用后查看状态。
- 本次仍按用户要求提供 ad-hoc / 无 Developer ID 签名的通用包，安装包和应用校验仍保留。公开版本及可信校验清单通过 [GitHub Releases](https://github.com/zero-times/agentupdate/releases) 提供；自动安装使用匹配架构的 DMG，发布时需同时上传 DMG 与 SHA256SUMS。应用 ZIP 提供完整 `.app` 归档。

## 锁屏执行与验证边界

开发、下载、安装测试、编译、打包和云端回写使用命令行及后台接口，不依赖点击解锁界面。本轮未出现锁屏阻塞，因此未触发锁屏告警；当前会话没有 email-notify MCP 工具，无法发送条件告警邮件，需要启用该 MCP 后在新会话加载。

真实安装测试均采用临时 HOME / Applications，未升级或替换日常 Codex、Claude、Deepseek。Apple Silicon 原生和 Rosetta 的执行范围以审核证据为准；尚无物理 Intel 与干净 macOS 15 设备的测试。
