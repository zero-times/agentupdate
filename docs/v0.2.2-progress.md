# v0.2.2 安装进度与直接升级

每次安装调用使用独立的 Tauri IPC Channel，进度只包含目标标识、阶段、下载字节和错误码，不包含本机路径、配置、下载 URL 或进程输出。CLI 队列逐项上报；下载使用有大小限制的流式读取，百分比由实际字节计算。没有 Content-Length 时显示已下载大小与不定进度。缓存制品仍校验完整性，准备、备份、安装和验证跟随后端执行阶段；失败和安全取消不显示成功。

桌面应用的新 install_app 命令在同一进程操作锁与跨进程锁内完成固定官方制品选择、准备与安装，保留所有签名、架构、恢复材料、占用与文件变化校验。CLI 点击后创建固定目标计划并直接顺序执行；桌面应用和本应用不再弹出二次安装确认。Self-update 退出前显示后台安装与重启阶段，后台进程核验替换并重启，重新打开后从持久安装记录显示最终结果。退出前不会显示虚假的 100% 安装完成。

主动检测会读取本机安装版本并重新查询该工具的官方渠道。CLI 由 Rust semver 比较语义版本（包括 prerelease 的数值顺序，忽略 build metadata 的优先级差异）；桌面应用沿用产品独立的数值版本比较。只在 update_available 时显示一键升级；未知、失败、已最新或本机较新不显示。后端也拒绝 latest 请求的相同、较低或无法比较版本，避免过时界面重复升级或意外降级。显式选择不同目标版本仍可执行。

验证使用隔离 HOME 和真实官方缓存 CLI 制品，以及临时 ad-hoc 签名通用 Claude 测试应用。测试构建中的进度阶段延迟和固定本地制品源只通过编译特性启用，生产构建没有这些入口。
