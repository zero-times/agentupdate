# 备份与恢复材料（AGE-8）

更新器必须先完成备份，没有跳过开关。恢复点保存完整旧 npm 包及其嵌套依赖、原命令链接、配置清单、原权限、SHA-256 和原始缺失状态。外层恢复目录 0700，配置内容和制品文件 0600；原权限只记录在清单，恢复时重新应用。备份与清单仅存在本机，不进入网络请求或诊断事件。

受管用户配置范围：Codex 的 `.codex/config.toml`、`auth.json`；Gemini 的 `.gemini/settings.json`、`oauth_creds.json`、`google_accounts.json`、`mcp-oauth-tokens.json`。项目配置、会话历史及外部服务状态不受管。遵循 CODEX_HOME / GEMINI_CLI_HOME 的绝对目录覆盖。根目录和中间目录的符号链接拒绝；相对文件链接只在同一配置根内解析，目标一并保存。包内相对链接只允许指向包内，外部或损坏链接停止准备。

源文件按无跟随链接方式读取；扫描、复制后内容校验和源复核均通过才发布恢复点。限制单次快照 2 GiB、100,000 项，配置 64 MiB。空间检查要求两倍快照大小加 512 MiB 预留，不删除旧恢复点来腾空间。中断或失败保留 partial 材料，事务不能进入 installing。

旧版本恢复无需联网：快照保存实际已经验证的旧安装，而非只有主包 tarball。恢复服务从私有数据重建依赖树，再检查原版本及健康状态。权限不足、空间不足、来源变化及损坏失败均不修改实际安装。

验证：5 个自动化测试通过，覆盖内部链接及原权限、原始缺失、外部/损坏链接、不可读文件、复制期间变化、材料损坏、空间不足与路径越界。完整恢复点发布/读取与旧包重建测试通过。前端类型检查通过。真实完整安装与离线恢复在后续闭环集成验证。

按用户要求保留进行中，整个版本完成后统一进入审核。
