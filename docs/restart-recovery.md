# 未完成事务检查（AGE-13）

工作台启动先检查持久化事务，不自动重装、不直接判成功。应用全局锁或 npm prefix 锁仍被占用时，保留该进程状态；锁文件不删除，进程退出后由内核自动释放。

预检/备份/已准备阶段异常退出，标为 preparation_failed（INTERRUPTED_BEFORE_INSTALL）；安装/验证异常退出标为 needs_recovery；恢复异常退出标为 recovery_failed。运行计划暂停，需要用户明确继续其余项。保留旧材料、半成品、包旁保留目录和当前安装，不重复安装。检查恢复点完整性与当前命令范围/版本/健康状态，错误展示材料或安装不可用，不能变成成功。

有完好材料时，历史中的回滚入口离线重建原包和配置；材料损坏仍保留全部文件，并提供 docs/rollback.md 的人工恢复步骤。当前安装缺失也可从完好恢复点恢复。

验证通过：分别在 installing / recovering 持久化后删除 fixture 包，真实子进程持有两类锁时以 SIGKILL 退出；重开数据库准确识别未完成项、自动锁释放、计划暂停，离线恢复到原版本和原配置。运行中的锁持有者未被误判崩溃。证据 docs/evidence/age-13-restart.json。此处为隔离 Node 工具 fixture 的真实进程退出验证；真实 Codex/Gemini 端到端故障组合在 AGE-15 执行。

按用户要求保持进行中，整个版本完成后统一审核。
