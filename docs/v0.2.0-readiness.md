## 审核使用要点与边界

1. 将 AgentUpdate 拖入 /Applications 或 ~/Applications 后启动，使用检测入口查看本机工具；自更新仅支持标准 Applications 中的运行实例。
2. 缺失 CLI 首次安装依赖已有 Node.js 22.12+；终端 PATH 需包含 ~/.local/bin。Deepseek 当前官方 latest 为 RC，需明确勾选预发行版本。
3. 安装/更新页面完成下载、校验与备份后显示确认；目标 Codex / Claude 应用需先退出。CLI 更新与应用安装记录可用于恢复。
4. 当前支持固定目录中的工具，未知 Agent 需新增适配器。物理 Intel 和干净 macOS 15 尚未验证；Rosetta 成功不等同于物理 Intel 验收。
5. 远程 AgentUpdate Release 需提供 ZIP 和可信 SHA256；当前未公开发布新版本，自更新证据使用隔离的签名通用 fixture，无法将其解释为线上发行验收。
6. 下载、构建、测试和云端回写均使用后台/命令行，本轮未遇到锁屏阻塞。当前会话无邮件通知 MCP，未发送邮件。
