# 历史、导出与恢复点保留（AGE-14）

逐项历史显示原版、目标版、持久化阶段、错误码和恢复点。恢复点详情重新验证清单/所有载荷，显示配置根与受管路径、大小及保护原因，不读取配置值到界面。

脱敏日志采用字段和错误码白名单，仅导出工具、有效语义版本、阶段、时间、事务/恢复点标识与事件码；不导出本地路径、配置、凭据、完整实例对象或进程输出。未知事件/错误码替换为 REDACTED。

完整恢复点导出必须在界面明确确认敏感配置，并由后端再验证确认标志；包括原配置、完整旧包和已有变化副本。输出写到应用私有 exports/<UUID>，完整复制后复查内容与模式再发布。可打开访达查看，仅接受应用生成的 UUID，无任意文件路径或 shell 接口。导出前检查可用空间，不触碰日常安装。

手动清理受全局操作锁保护，只允许终止的事务，并要求同一实例存在更近、已验证的完整恢复点；进行中、待恢复、恢复失败、损坏或最近唯一恢复点均受保护。清理保留历史与 restore_deleted 事件，解除恢复点引用。没有自动删除恢复点或为了腾空间删除唯一备份。空间不足会停止新的备份/导出并提示清理。

验证：4 项集成测试通过，覆盖秘密配置及未知码不会进入日志、完整导出显式确认与逐载荷校验、目录700/文件600权限、最新/进行中材料保护、旧点清理后历史和新恢复点仍可用，以及与运行操作的锁竞争拒绝。证据 docs/evidence/age-14-history.json。界面接入恢复点详情、敏感导出确认、清理确认和访达入口；完整操作路径在 AGE-15 验证。

按用户要求保持进行中，整个版本完成后统一审核。
