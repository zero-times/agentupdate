# v0.2.1 界面设计与在线升级测试

工作台采用深墨蓝导航、暖灰工作区和铜色提示。侧栏将 CLI、桌面应用与本应用更新分开，版本、安装来源和恢复操作集中在对应页面；窄于 900px 时工具卡片改为单列，最低窗口宽度 720px。保留系统深色模式、键盘焦点、原生对话框和减少动画偏好。

所有业务组件保持挂载，切换页面不丢失实例选择、目标版本或安装进度。AgentUpdate 有新版本时，侧栏显示提示。首次进入仍可自动发现工具与检查发布版本。

从 v0.2.0 测试：安装于 `/Applications` 或 `~/Applications`，点击旧界面底部“检查应用更新”，检测到 v0.2.1 后点击“下载更新并安装重启”。确认下载与备份完成后安装并重启；在新界面左下角核对 v0.2.1。v0.2.1 的更新入口位于侧栏“本应用更新”。应用 ZIP 用于手动归档，本应用在线升级使用 DMG 与 SHA256SUMS。

真实 WebView 验证覆盖导航可见性、切换后保留组件和实例选择、无横向溢出，以及更新确认、批量更新、恢复、脱敏导出和恢复点保护。验证只修改隔离的 HOME 与固定的 CLI 测试安装。生产包另行核对通用架构、版本、签名完整性、DMG/ZIP 安装和启动；发布后以真实公开元数据验证更新识别与两种架构匹配。

2026-10-14 验证结果：TypeScript 与 Rust 格式检查通过；57 项常规 Rust 测试及 1 项嵌套子进程锁测试通过。真实 WebView 的 Apple Silicon 和 Rosetta 导航、渲染及能力边界检查通过；720 × 540 最小窗口自动检查和人工查看三页通过。隔离 CLI UI 更新/恢复流程在两种执行架构通过，原安装包树与测试配置均恢复一致。Rosetta 首次等待恢复对话框超时，延长测试等待并在前台复验后通过；生产更新流程没有因此修改。

证据：[WebView](evidence/v0.2.1-desktop.json)、[arm64 UI](evidence/v0.2.1-ui-arm64.json)、[Rosetta UI](evidence/v0.2.1-ui-x86_64.json)。生产安装包验证记录随 Release 上传，避免构建后记录写入源码而破坏干净构建来源。
