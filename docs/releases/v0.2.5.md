# AgentUpdate v0.2.5

- 发现 AgentUpdate 新版本时，在工作台显示醒目的更新横幅；侧栏使用“新版本”文字徽标，点击横幅可直接进入更新页面。CLI 和桌面应用的可更新状态也使用强调色突出显示。
- 侧栏与页面标题“本应用更新”统一改为“版本更新”，检查按钮改为“检查版本更新”。
- 修复 Claude Code CLI 的 Homebrew 更新异常：更新前刷新 Homebrew API 目录，并核对版本、架构、下载地址与校验值，避免本地目录过期导致“命令成功但实际未升级”，最终误入校验失败。目标变化或目录刷新失败时在修改安装前停止，并提示重新检测。

可在旧版“本应用更新”中检查并安装 v0.2.5。

若先前 Claude CLI 更新已经显示“待恢复”，请先在更新任务中回滚至原版本，再重新检测并升级。

macOS 15+，Apple Silicon / Intel 通用包。沿用已有 ad-hoc 完整性签名发布方式，无 Developer ID 签名与 Apple 公证。Intel 架构通过 Apple Silicon 上的 Rosetta 验证，物理 Intel 和干净 macOS 15 未测试。
