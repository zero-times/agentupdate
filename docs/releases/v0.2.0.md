# AgentUpdate v0.2.0

优先补齐本机常用工具的检测、首次安装和升级：Codex CLI、Claude Code CLI、Deepseek Harness，以及 Codex / Claude 桌面应用；保留 Gemini CLI 和 ChatGPT 支持。

- Codex Homebrew Cask 开放升级及旧安装恢复；当前用户拥有的标准 Homebrew npm 安装也可管理。
- 缺失 CLI 可一键安装至用户目录；已有实例沿用来源、完整旧版本和配置备份及恢复点。
- Claude 新 npm 平台原生分发通过官方 manifest SHA256 核验后安装，不运行 npm 生命周期脚本。
- Deepseek 使用官方 `dsh` / `@deepseek-ai/dsh` 渠道；目前 latest 为 RC，需明确选择预发行版本。覆盖全局及各 profile 的配置备份，保留依赖投影。
- Codex / Claude / ChatGPT 可在 AgentUpdate 内下载、校验、备份、安装和恢复。官方包验证厂商签名与架构；目标应用运行时提示退出后重试。
- AgentUpdate 可在应用内安装更新并重启，后台 helper 在旧进程退出后替换应用。API 限流时复核官方 latest Release 和 SHA256SUMS，缺失可信校验不会自动安装。

macOS 15+，Apple Silicon / Intel 通用包。CLI 首次安装依赖 Node.js 22.12+，终端 PATH 应包含 `~/.local/bin`。Deepseek 当前官方 latest 为 RC，需明确选择预发行版本。

下载 DMG 后将 AgentUpdate 拖入 `/Applications` 或 `~/Applications`；应用内更新也使用通用 DMG，应用 ZIP 提供完整 `.app` 归档。发布附件包含 `SHA256SUMS` 和源码构建清单。按用户确认的交付要求，本版本采用 ad-hoc 完整性签名，未完成 Developer ID 签名与 Apple 公证。Apple Silicon 和 Rosetta 验证通过，物理 Intel 与干净 macOS 15 尚未测试。使用及限制见 `docs/v0.2.0-install-and-update.md`，核验结果见 `docs/v0.2.0-readiness.md`。
