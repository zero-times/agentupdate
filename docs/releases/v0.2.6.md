# AgentUpdate v0.2.6

- 修复旧失败任务处于“待恢复”时，点击 Claude CLI 等工具升级仍只显示通用报错的问题。对应工具现在直接提供“查看待处理任务”入口，并定位到原任务的恢复操作。
- 待恢复提示列出工具名称与原版本，说明先恢复旧版本、再重新检测升级；批量升级会跳过仍被旧任务占用的工具。
- 修复恢复成功后顶部仍显示旧“待恢复”提示的问题，提示随实时任务状态更新，无需重启应用。

可在“版本更新”中检查并安装 v0.2.6。旧任务仍须通过恢复预览确认处理，配置变化时保留原有副本与确认流程。

macOS 15+，Apple Silicon / Intel 通用包。沿用 ad-hoc 完整性签名发布方式，无 Developer ID 签名与 Apple 公证。Intel 架构通过 Apple Silicon 上的 Rosetta 验证，物理 Intel 和干净 macOS 15 未测试。
