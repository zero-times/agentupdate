# AgentUpdate v0.2.3

- 每个 CLI 安装实例新增“打开”按钮。在弹窗中选择最近项目、修改目录或新增目录，然后在 macOS 系统终端启动对应 CLI。
- 最近使用的 20 个项目目录在本机保存，跨 CLI 共享、去重，应用重启后保留。无效目录和失效的命令会显示错误。
- Deepseek Harness 默认使用 `dsh --profile web`，修复直接启动时缺少 `--profile` 的错误。弹窗可填写其他已安装的 profile；`tui` 不是内置模板，`desktop` 由 Harness 桌面应用管理。
- 启动使用所选安装实例的实际命令路径，支持中文、空格和引号等路径，并为 npm CLI 补齐 Node 环境。

在 v0.2.2 中点击“本应用更新 → 检查应用更新”，即可下载安装 v0.2.3。首次打开 CLI 时，macOS 可能询问是否允许 AgentUpdate 控制“终端”。

macOS 15+，Apple Silicon / Intel 通用包。沿用已有发布方式，采用 ad-hoc 完整性签名，无 Developer ID 签名与 Apple 公证。x86_64 在 Apple Silicon 上通过 Rosetta 验证，物理 Intel 和干净 macOS 15 未测试。
