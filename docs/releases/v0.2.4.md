# AgentUpdate v0.2.4

- 顶部新增“收起到菜单栏”图标；点击 macOS 菜单栏的 AgentUpdate 图标即可重新打开面板。右键菜单提供打开、收起和退出。
- 关闭窗口时收起面板，保留正在执行的任务；安装或恢复尚未完成时阻止退出并显示提示。
- 安装完成记录和完成进度默认隐藏，恢复旧版本或恢复为未安装的入口可按需展开。进行中和失败任务仍显示。
- 移除“更新有底，恢复有据”等宣传文案，精简面板标题和说明。

可在旧版“本应用更新”中检查并安装 v0.2.4。

macOS 15+，Apple Silicon / Intel 通用包。沿用已有 ad-hoc 完整性签名发布方式，无 Developer ID 签名与 Apple 公证。Intel 架构通过 Apple Silicon 上的 Rosetta 验证，物理 Intel 和干净 macOS 15 未测试。
