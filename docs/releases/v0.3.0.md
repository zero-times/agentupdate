# AgentUpdate v0.3.0

- UI 更新：全应用加载状态视觉升级。所有"检测中…/正在扫描…"纯文本替换为统一旋转 Spinner；扫描与版本检测时显示骨架屏占位；应用启动显示骨架屏而非单行文字。
- 三个工作台视图（CLI 工具 / 桌面应用 / 版本更新）切换增加淡入滑动过渡；工具卡片首次出现带 stagger 渐入；侧栏连接状态点在未连接时呼吸闪烁。
- 空状态增加 ◌ 标记，不再是纯文本；进度条确定性进度增加流光效果；安装成功时显示打勾动画并保留为紧凑的完成行，不再直接消失。
- 清理无引用的 `AgentList.tsx` 遗留组件。
- 深色模式与 `prefers-reduced-motion` 保持兼容：减弱动态偏好下所有动画自动关闭。

可在"版本更新"中检查并安装 v0.3.0。

macOS 15+，Apple Silicon / Intel 通用包。沿用 ad-hoc 完整性签名发布方式，无 Developer ID 签名与 Apple 公证。Intel 架构通过 Apple Silicon 上的 Rosetta 验证，物理 Intel 和干净 macOS 15 未测试。
