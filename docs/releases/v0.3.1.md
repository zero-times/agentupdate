# AgentUpdate v0.3.1

- 修复 Claude Code（Homebrew Cask 与官方原生安装）升级在准备阶段报 `ARTIFACT_SIZE` 的问题。旧版对下载制品统一使用 256 MiB 上限，而 Claude 原生制品是单个可执行文件，2.1.304 已达 271,161,296 字节（约 258.6 MiB），因此下载在写入前就被拒绝，事务停在「准备失败 · 安装未修改」。
- 原生单文件制品（Claude 原生二进制、Codex Homebrew 归档）改用与共享下载器一致的 1 GiB 上限；npm 包制品仍保持 256 MiB 上限，隔离与校验流程不变。下载后仍逐字节校验官方 SHA-256，并在隔离目录验证版本与架构，未通过不会改动原安装。
- 验证：真实下载 `https://downloads.claude.ai/claude-code-releases/2.1.304/darwin-arm64/claude`（271,161,296 字节）通过 SHA-256 校验；Homebrew cask 元数据与本机升级目标的 URL/SHA-256 一致。

升级后可在「版本更新」中重新检测并安装 Claude Code 2.1.304。之前停留在准备失败的任务未修改安装，可直接重新检测重试。

macOS 15+，Apple Silicon / Intel 通用包。沿用 ad-hoc 完整性签名发布方式，无 Developer ID 签名与 Apple 公证。Intel 架构通过 Apple Silicon 上的 Rosetta 验证，物理 Intel 和干净 macOS 15 未测试。
