# AgentUpdate v0.2.1

重新设计工作台界面，让常用工具管理与本应用更新更容易找到。

- 全新侧栏导航，分别管理 CLI 工具、桌面应用和 AgentUpdate 自身更新。
- 统一工具卡片、版本信息、更新计划与恢复记录，优化较小窗口和深色模式。
- 切换页面保留实例选择、版本与任务状态；发现 AgentUpdate 新版本时，侧栏显示提示。
- 保留一键安装升级、旧版本与配置备份、恢复和后台安装重启流程。

## 测试本应用在线升级

在已安装的 v0.2.0 中点击“检查应用更新”，检测到 v0.2.1 后点击“下载更新并安装重启”。应用会下载通用 DMG，核对 SHA256、备份旧应用，确认后由后台进程完成替换与重启。成功后左侧应显示 v0.2.1，并出现全新侧栏界面。升级前将旧版安装到 `/Applications` 或 `~/Applications`。

macOS 15+，Apple Silicon / Intel 通用包。发布附件包含 DMG、完整 `.app` ZIP、`SHA256SUMS`、源码与构建清单、安装包验证记录。按已确认的交付要求使用 ad-hoc 完整性签名，未完成 Developer ID 签名或 Apple 公证。Intel 执行通过 Rosetta 验证，物理 Intel 和干净 macOS 15 未测试。
