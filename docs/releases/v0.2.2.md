# AgentUpdate v0.2.2

- CLI、桌面应用与 AgentUpdate 自身更新统一显示安装进度。下载时显示实际传输大小和百分比；备份、制品准备、安装和验证显示当前阶段。无法确认文件总大小时保持不定进度，只有验证安装成功后才显示完成。
- 点击升级后自动下载、校验、备份与安装，无需再次确认。批量 CLI 更新按顺序执行；失败项及恢复点继续保留。回滚、敏感导出和恢复点删除仍保留各自确认。
- 每个 CLI 和桌面应用均有“检测更新”按钮，主动刷新本机版本与官方渠道。只有严格更新的版本才显示一键升级；已最新、本机较新、未知版本或检查失败不会提供重复升级。
- 更新成功后自动重新检测并隐藏升级按钮。新工具仍可一键安装；指定目标版本与恢复功能继续提供。

在 v0.2.1 中点击“本应用更新 → 检查应用更新”，发现 v0.2.2 后下载安装。此次升级由旧版 v0.2.1 执行，仍会有旧版的安装确认；重启进入 v0.2.2 后，后续安装升级采用直接安装与进度显示。

macOS 15+，Apple Silicon / Intel 通用包。采用用户已接受的 ad-hoc 完整性签名，无 Developer ID 签名与 Apple 公证。Intel 执行通过 Rosetta 验证，物理 Intel 与干净 macOS 15 未测试。
