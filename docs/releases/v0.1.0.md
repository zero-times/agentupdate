# AgentUpdate v0.1.0 — macOS MVP

审核用 Release 更新说明。当前无 Developer ID 签名的候选包已按用户要求用于本地使用；公开发布前另行核对签名、公证和独立环境验收。

首版支持当前用户拥有且可写的 Codex CLI 与 Gemini CLI npm 安装实例：发现实际路径、来源、架构与当前版本，选择固定版本或最新稳定版，单项更新和顺序批量更新。

新增 Claude Code CLI：支持用户 npm、默认用户原生与标准 Homebrew Cask 的来源检测和一键升级，沿用强制备份、安装校验与恢复点。修复 Homebrew Codex CLI 当前版本无法读取的问题。新增 Codex、Claude、ChatGPT 桌面应用的本机版本与公开渠道更新检测，提供官方入口与架构匹配下载。

修改前强制备份受管配置和完整旧安装，准备失败停止该项。更新失败保留恢复点，可恢复原版本与配置；更新后配置变化会先保存当前副本。支持任务历史、逐项结果、失败暂停、安全取消、实例锁和异常退出后的未完成事务检查。

历史提供脱敏日志、需明确确认的完整恢复点导出，以及保护最近唯一恢复点和待恢复事务的手动清理。

应用从本仓库 GitHub Releases 检查自身版本，提供更新说明和当前架构的下载入口；自动检查最多每 24 小时一次，支持手动检查。

## 系统与工具

- macOS 15+，通用 arm64 / x86_64 应用；外部 Node.js ≥22.12 / npm 需要可用且架构兼容，应用不内置 Node/npm。当前仅有 Apple Silicon 原生和 Rosetta 验证，物理 Intel 与干净 macOS 15 待验收。
- 首批验证版本：Codex CLI 0.162.0 ↔ 0.162.1，Gemini CLI 0.62.0 ↔ 0.63.0。
- 系统级 npm、Codex Homebrew 与其他未验证原生来源仅展示；Claude 原生及标准 Homebrew 支持最新稳定版升级。Homebrew 与官方原生发布节奏可能不同。
- 配置备份/恢复可能包含凭据文件，完整导出应按敏感材料保管；不管理登录认证或 Keychain。
- Windows/Linux、应用自身自动替换和无人值守更新不在此版本范围。

## 下载与校验

版本和 tag：`0.1.0` / `v0.1.0`。拟发布地址：<https://github.com/zero-times/agentupdate/releases/tag/v0.1.0>。

安装包：`AgentUpdate-0.1.0-macos-universal.dmg`。附属归档：`AgentUpdate-0.1.0-macos-universal.app.zip`。校验信息：`SHA256SUMS` 和 `release-manifest.json`，校验文件须与使用的包来自同一轮构建。

安装后使用和恢复见 `docs/macos-v0.1.0-usage.md`；发布前复核见 `docs/macos-release.md`。当前候选仍为 ad-hoc，正式签名、公证及干净 macOS 15/物理 Intel 冒烟未完成。
