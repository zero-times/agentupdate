# AgentUpdate v0.4.0

- 支持同时升级多个 CLI 工具，最多四项并发。也可在一个工具升级期间继续启动其他工具或桌面应用的升级，各自显示进度与结果。
- 共用安装目录的 CLI、同一工具的多个实例以及相同桌面应用的安装仍依次执行，避免安装文件、配置或包管理器发生冲突。单项升级失败后，其余项继续执行；取消会跳过尚未开始修改安装的项目。
- 移除恢复版本、回滚旧应用和恢复为未安装的按钮、弹窗及对应调用接口。升级前仍保存备份，任务记录保留结果、错误码和脱敏日志导出；历史失败任务不再要求恢复旧版本才能重新检测升级。若安装损坏、无法检测，请通过工具官方渠道重新安装。
- AgentUpdate 自身更新仍独占执行，其他安装或升级进行中无法开始本应用更新，防止重启打断任务。

macOS 15+，Apple Silicon / Intel 通用包。沿用 ad-hoc 完整性签名发布方式，无 Developer ID 签名与 Apple 公证。Intel 架构在 Apple Silicon 上通过 Rosetta 验证；物理 Intel 和干净 macOS 15 未测试。
