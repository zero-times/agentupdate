# 顺序队列与安全取消（AGE-12）

批量计划按 ordinal 逐项执行，失败持久化 paused。用户明确选择回滚失败项、继续剩余项或结束。成功项不自动撤销，失败项不自动重试，每项目标与恢复点独立。界面已接入整个计划执行、暂停继续与结束入口。

应用内操作互斥，加上跨进程应用锁和每个 npm prefix 的排他锁，更新与回滚不能并发修改同一实例或共享 prefix。锁采用稳定文件与内核 flock，禁止链接/错误所有者，文件不删除；进程退出后内核释放，不依据 PID 猜测或删除陈旧锁。

取消请求通过 SQLite schema 2 持久化。schema 1 自动迁移并保留计划与事务。准备阶段在适配器安全边界检查取消，标记 cancelled；安装开始后不强杀安装/验证，记录真实最终结果后取消后续项。后台工作使用独立存储连接，取消和进度查询继续可用。
