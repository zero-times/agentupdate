# 菜单栏面板与记录展示（AGE-25）

顶部按钮和窗口关闭操作隐藏主窗口，保留 WebView、页面选择和任务状态。菜单栏图标为 macOS 模板图像，随系统明暗配色显示；左键松开打开窗口，右键提供打开、收起和退出。Dock 重新打开事件也恢复主窗口，并取消最小化。

退出事件检查已有操作锁，安装或恢复忙碌时阻止退出、显示主窗口并发送提示。自更新已进入重启流程时允许退出，让现有后台安装助手继续工作。菜单栏创建失败会中止启动；隐藏命令也检查图标存在，避免无法找回窗口。

成功记录默认收在关闭的原生 details 中，恢复功能按需展开。失败、待处理和进行中的任务保持可见。混合计划中的成功事务单独折叠；成功进度组件不再显示。数据、恢复材料和后端历史没有删除。

## 提交前自审

审查范围包括窗口生命周期、托盘回调、退出与操作锁、自更新退出、Tauri 权限、生产与验证构建隔离、CLI/应用历史和混合成功失败计划。

发现并修复：退出受阻的前端事件缺少 listen/unlisten 权限；有失败事务的已结束计划可能显示成功记录。新增权限只作用于本地主窗口，验证探针仅在 desktop-validation 构建启用，生产打包另检查探针标记不存在。

未发现剩余阻断性代码问题。此记录为本次实现的自审，不代表独立评审。

## 验证范围

原生 WebView 面板测试验证顶部收起、菜单栏回调打开、关闭后窗口与图标保留、最小化恢复、忙碌退出提示、成功记录默认折叠和失败记录可见。探针调用生产回调，未声称完成物理鼠标菜单栏点击；手工查看已确认顶部按钮和精简后的界面。

全量 npm run check 在 fault_hardening 的配置权限恢复测试遇到 AGENT_RUNNING；restart_recovery 的故障恢复测试和 rollback_recovery 的三项恢复测试同样被阻止，其中冲突配置测试因恢复前返回 AGENT_RUNNING，状态保持 Succeeded 而非预期 RecoveryFailed。本机存在以裸命令 codex 运行的用户进程，未修改的实例占用检查保守地将其视为占用 Codex。未终止用户进程或放宽保护。因此本次无法声称全量回归和真实 Codex 更新恢复流程通过。具体面板和桌面边界证据见 docs/evidence；生产包验证随 Release 附件提供。

最终验证：TypeScript、Rust 格式检查、通用验证包构建、12 项原生面板检查及 native/Rosetta WebView 权限边界检查通过。后续独立执行 history_retention、install_features、npm_updates、progress、restart_recovery、rollback_recovery 和 transaction_storage，共 23 项通过、4 项受进程占用影响失败、9 项按原定义忽略。
