# v0.1.0 整版复核（追加 Claude 功能前的历史记录）

2026-10-13 在 AGE-16 新版交付后复核。功能实现和本机验证已有完整证据，候选安装包可供检查；按原定完成标准，整个版本仍未满足统一审核条件。云端 AGE-2 为 `blocked`（version 5），AGE-16 为 `blocked`（version 9）。用户要求整体完成后统一审核，其余 14 个子任务保持 `in_progress`，未提前标为验收通过。

## 已确认的交付

- AGE-3–15、AGE-17 已实现并自检；后端 43 项常规测试、前端类型检查与生产构建、Rust 格式检查通过。沿用此前原始验证结果，本轮没有重新运行这些测试。
- 两工具完整 React/WebView 操作通过：Codex 0.162.0 → 0.162.1 → 0.162.0，Gemini 0.62.0 → 0.63.0 → 0.62.0；包括选择、计划确认、顺序更新、恢复、脱敏导出和恢复点保护。arm64 为原生执行，x86_64 为 Apple Silicon 上的 Rosetta 执行；原安装全树及人工配置恢复一致。
- 故障注入、更新失败、恢复再次失败后重试、批量暂停、锁、取消和异常退出恢复有对应证据。应用自身 GitHub Releases 检查已实现；2026-10-13 实际端点成功返回 `no_releases`。
- AGE-16 最终候选位于 `release-artifacts/v0.1.0/candidate-20261013T012754075Z/`，包含通用 DMG、真实 `.app.zip`、SHA256SUMS、制品与源码清单、更新说明及版本检查 fixture；新版云端附件已回读。
- 本轮独立复核：5 项文件的大小和 SHA-256 与清单一致，65 个构建输入与当前源码一致，源码总摘要一致；候选生产二进制哈希与此前整版审计一致。`unzip -tq` 和 `hdiutil verify` 均通过。
- 包内版本 0.1.0、最低 macOS 15.0、arm64/x86_64 两个切片；生产业务命令存在，验证入口和故障注入已剔除。原交付记录中的临时安装、双架构启动存活和卸载冒烟通过。该启动检查尚未覆盖安装包内两工具交互。

旧的归档扩展名错误、制品输出被 Vite 清空、缺少制品/清单/校验/说明等问题均已修复，已从汇总 JSON 的当前阻塞中移除。
