## 审核范围与待补验

当前审核覆盖本机功能和用户接受的无 Developer ID 签名候选。物理 Intel、干净 macOS 15 及安装包内完整工具交互尚未验收；现有结果包括验证构建的 WebView 闭环和生产候选包的启动冒烟，二者分别记录。Claude Homebrew 的真实升级未在日常安装上执行，当前目录版本与本机一致；升级后会核对二进制 SHA-256、版本和架构，未一致前不报成功。

Developer ID、公证、固定干净 Git 提交和正式分发准备未完成。仓库无 HEAD，源码按文件哈希固定在清单；未提交/推送代码，未创建公开 GitHub Release。桌面应用只检查并打开官方入口，不自动覆盖运行中的应用；公开目录可能晚于厂商分批发布。

云端 AGE-16 由另一会话绑定，本轮不接管其状态。当前本地交付政策和新增包结果汇总到 AGE-2；本会话拥有的功能任务统一提交 `in_review`，等待用户审核，未标为已验收。
